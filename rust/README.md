# Dockview (Rust)

Rust rewrite of Dockview, developed on branch `migration/rust`.
The original C#/WPF app in the repository root is kept as reference
until feature parity is reached, then removed or archived.

- `crates/dockview-platform` — capture, audio, stream selection, settings
- `crates/dockview-app`  — window, D3D11/DXGI rendering, UI
